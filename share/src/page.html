    What this is

    This single page carries files that were packed with Crush, together with everything needed to unpack them. Your browser does all the work: nothing is uploaded, nothing is installed, and the page makes no network connections at all — it works offline.

    Every file is checked against a fingerprint (SHA-256) taken when it was packed. A file is only offered for saving if it matches, so what you save is exactly what was sent.

    Technical details

    Made with Crush. Large archives need memory roughly equal to their unpacked size; on a phone, archives up to a few hundred megabytes are the practical limit.
